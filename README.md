# Mobile Field Test QA Lab — Domain Knowledge Pack

WE17 모바일 필드 테스트 직무를 참고한 교육용 지식 문서 모음. 실제 iPhone 17과 Windows 개발 환경을 전제로 한다.

## 사용법
1. `docs/domain/` 문서를 순서대로 읽고 기술 개념과 테스트 한계를 검토한다.
2. Codex는 구현 전에 관련 문서를 읽고 요구사항 및 테스트케이스의 근거를 연결한다.
3. 근거가 없는 임계값을 발명하지 않으며, 실제 기기 테스트를 수행하지 않은 결과를 PASS로 표시하지 않는다.
4. GitHub 업로드는 저장소 생성·연결 후 사용자가 승인한 커밋/푸시로 수행한다.

## 범위
교육용 초안 8개 문서. 실제 테스트 결과나 검증 완료된 표준 사양을 포함하지 않는다.
