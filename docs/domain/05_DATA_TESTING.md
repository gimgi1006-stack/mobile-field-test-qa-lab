# 데이터 연결과 품질

> 프로젝트: Mobile Field Test QA Lab | 상태: 기초 교육용 초안 | 검증 수준: 개념 설명, 표준 조항별 대조 미완료

## 1. 핵심 개념

인터넷 접속 성공 여부, 응답 지연시간, 전송 속도는 서로 다른 측정 항목이다. 하나의 웹사이트 접속 성공만으로 전체 네트워크 품질을 확정할 수 없다.

## 2. QA 엔지니어가 확인할 사항

Wi-Fi 끄기 등 조건을 확인한 뒤 동일한 목적지와 반복 횟수로 테스트한다. 테스트 서버·시각·접속 방식·결과를 기록한다.

## 3. 관련 테스트케이스

DATA-001, DATA-002, DATA-003

## 4. iPhone 17 + Windows 제약

- iPhone에서 통화 및 셀룰러 설정은 기본적으로 수동 조작한다.
- Windows의 Python/pytest는 테스트 관리 시스템의 검증 및 수집된 측정값 분석에 사용한다.
- 실제 모뎀 내부 로그, 무선 품질, 프로토콜 메시지는 일반적인 Windows 연결만으로 확보된다고 가정하지 않는다.
- 실제 측정 결과, 예제 데이터, 자동화된 검증 결과를 분리한다.

## 5. 학습 확인 질문

1. 이 기능의 정상 동작을 어떤 관찰 가능한 증거로 판단할 수 있는가?
2. 실패했다면 어떤 환경 정보를 기록해야 재현 가능성이 높아지는가?
3. 자동으로 검증 가능한 것과 수동 확인이 필요한 것은 무엇인가?
